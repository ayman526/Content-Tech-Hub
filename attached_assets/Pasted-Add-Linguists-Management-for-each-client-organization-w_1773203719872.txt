Add “Linguists Management” for each client organization with 3 linguist types:
1) System Pool (platform-managed linguists)
2) Preferred Linguists (client-approved/favorites from system pool)
3) Internal Linguists (client’s own staff invited by email)

KEY BUSINESS RULE
When a client selects INTERNAL LINGUISTS for a job workflow (Human Revision or Human Translation), show a clear message:
“Since you selected Internal Linguists, there will be no charge for human revision/translation credits for this job.”
Then enforce it in billing logic:
- If workflow = HUMAN_REVIEW and linguist_source = INTERNAL => credits_used_for_human = 0
- If workflow = HUMAN_TRANSLATE and linguist_source = INTERNAL => credits_used_for_human = 0
- AI translation credits are still consumed normally unless plan rules say otherwise.
- For SYSTEM_POOL or PREFERRED linguists, human credits follow the standard conversion rules.

LINGUISTS TAB (Client Dashboard)
Create a new dashboard tab: “Linguists”
Functions:
1) Invite internal linguists by email:
- Client admin enters email + selects role = LINGUIST
- Client admin selects allowed language pairs for the invited linguist (multi-select)
- System sends invitation email with secure token link:
  - Accept invitation => account creation/login
  - On acceptance, user is added to org as LINGUIST and a LinguistProfile is created with linguistType = INTERNAL
2) Manage preferred linguists:
- Client can browse system pool linguists and add/remove them as “Preferred”
- Preferred linguists remain SYSTEM type globally but appear as PREFERRED inside that org
3) View system pool linguists (read-only list or limited browsing)
- Show basic profile info and supported language pairs
